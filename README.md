# FrascoClub · landing page do grupo de ofertas

Página que abre pelo link da bio do [@frascoclub](https://www.instagram.com/frascoclub/) e leva pro grupo de ofertas no WhatsApp.

## Arquivos

- `index.html`: a página (HTML e CSS num arquivo só)
- `logo.png` e `simbolo.png`: logo do FrascoClub
- `marcas/`: logos do Mercado Livre, da Shopee e da Amazon (SVG, Wikimedia Commons)

## Link do grupo

No fim do `index.html`, trocar o `#` pelo link da Comunidade do WhatsApp:

```js
const LINK_DO_GRUPO = "#";
```

Os dois botões usam esse link.
